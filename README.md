# claude-plugins

Claude Code plugins published by eJobs.

## Install

Inside Claude Code:

```
/plugin marketplace add Ejobs/claude-plugins
/plugin install ejobs@ejobs-cli
```

## Available plugins

| Plugin  | Description                                                                                         |
|---------|-----------------------------------------------------------------------------------------------------|
| `ejobs` | Agent-first `ejobs-cli` wrapper — candidate CV, job search, company job posting & applicant tools. |

Additional eJobs plugins will land as sibling directories; the marketplace
address above stays the same.
